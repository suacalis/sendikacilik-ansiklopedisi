# Türkiye Sendikacılık Ansiklopedisi — aranabilir dijital sürüm

Cilt 1–3 (1996–1998), 2.773 madde. OCR metninden otomatik temizlenmiştir; düzeltme ve madde ekleme araçları içerir.

**Site:** https://suacalis.github.io/sendikacilik-ansiklopedisi/

## Dosyalar
- `index.html` — uygulama (arama, grafikler, gönderme ağı, düzeltme/ekleme araçları)
- `ansiklopedi-veri.js` — tüm madde verisi (~11,7 MB)

İki dosya aynı klasörde durmalıdır.

## Güncelleme
1. Sitede düzeltme / ekleme yapın (değişiklikler tarayıcınızda saklanır).
2. **Kaydet / Dışa aktar → GitHub için güncel veri dosyasını indir** ile yeni `ansiklopedi-veri.js` dosyasını indirin.
3. Depoda **Add file → Upload files** ile aynı adlı dosyanın üzerine yükleyin.

> Uyarı: Büyük dosyaları GitHub'ın web düzenleyicisinde (kalem simgesi) açıp yeniden adlandırmayın ya da düzenlemeyin; içerik silinebilir. Dosya adını bilgisayarınızda değiştirip yükleyin.
